# 대한(주) 자동화 시스템

영업/전략기획 업무 자동화를 위한 프로젝트입니다. 문서(제안서, 기안문, 전략기획 보고서 등) 관리는 이 시스템의 일부입니다.

## 폴더 구조

```
.
├── docs/
│   └── proposals/     # 제안서, 기안문, 전략기획 보고서 (HACCP 규정 및 daehan-proposal-style 준수)
├── src/
│   └── automation/    # 자동화 스크립트, 워크플로우
├── package.json
└── .gitignore
```

## 문서 작성 원칙

`docs/proposals/` 하위 문서는 HACCP 규정과 절차를 준수하고, 어투/스토리 구조/비주얼 원칙은 `daehan-proposal-style` 스킬을 따릅니다.

## 자동화 스크립트

`src/automation/` 하위에 업무별 자동화 스크립트를 추가합니다. (예: 문서 생성, 데이터 수집, 알림 발송 등)

### 5톤 계란 운송차량 손익 관리

- 데이터 파일: `data/vehicle/5톤계란운송_손익관리.xlsx`
  - `고정비설정`: 단가/기사월급/하이패스/차량보험 등 거의 안 바뀌는 값
  - `일일기록`: 매일 입력 (날짜, 농장, 판수, 차량유지내용/비용, 하이패스)
  - `월별손익`, `연도별수익률`: 일일기록을 수식(SUMIFS)으로 자동 집계
- 월별 총액 요약 문구 생성 (광성/에그랑 등 거래처와 금액 대조 후 세금계산서 발행용):
  ```
  python3 src/automation/monthly_summary.py [연도] [월]
  ```
  인자를 생략하면 이번 달 기준으로 계산합니다. 엑셀 수식 캐시가 아니라 `일일기록` 원본 데이터를 직접 계산하므로 항상 정확합니다.
